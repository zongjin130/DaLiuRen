# 大六壬

一个基于 Python 的大六壬排盘与断课命令行工具。

## 功能

- 根据日期时间计算干支与真太阳时
- 构建天地盘、四课、三传等课盘信息
- 支持按问题类型进行基础断课
- 使用 Rich 在终端中格式化展示结果

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 项目结构

- `main.py`：命令行入口、参数处理、运行与结果展示
- `core/`：排盘、干支、历法、地点与断课逻辑
- `requirements.txt`：Python 依赖

> 本项目用于传统术数研究与软件实践，结果仅供参考。
